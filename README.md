# Сайт ЗДО №45 «Калинка» — [dnz45.vn.ua](https://dnz45.vn.ua)

Офіційний сайт комунального закладу «Дошкільний навчальний заклад №45 Вінницької міської ради».
Статичний сайт (HTML + CSS + JavaScript без збирання), хостинг — **Vercel**, автодеплой з гілки `main`.
Вміст редагує адміністрація закладу прямо на сайті — через вбудований редактор (вхід через GitHub).

## Структура репозиторію

```
├── index.html               головна сторінка (має лежати в корені)
├── pages/                   усі інші сторінки сайту
│   ├── _template.html       шаблон нової сторінки (скопіювати й заповнити)
│   ├── _blocks.html         каталог готових блоків (кнопки, картки, сітки…)
│   └── *.html               сторінки: pro-zaklad, grupy, kontakty, …
├── assets/
│   ├── css/styles.css       ЄДИНА таблиця стилів (зміст — на початку файлу)
│   ├── js/site.js           спільне: шапка, меню, футер, анімації, картки, «гарний текст», фото/документи
│   ├── js/editor.js         редактор вмісту «на місці» (з'являється після входу)
│   ├── js/pages/*.js        скрипт конкретної сторінки (одна сторінка — один файл)
│   └── img/                 логотип, іконки, прев'ю для соцмереж
├── content/*.json           ВЕСЬ вміст сайту (тексти, люди, документи) — його змінює редактор
├── images/                  фото: sadochok.jpg + uploads/ (усе, що завантажено через редактор)
├── api/                     серверні функції Vercel: вхід у редактор (auth, callback), передеплой (deploy)
├── vercel.json              маршрути, переадресації, заголовки безпеки
├── sitemap.xml, robots.txt  для пошукових систем
└── README.md
```

### Як працюють адреси

Сторінки лежать у `pages/`, але відкриваються з кореня: `dnz45.vn.ua/kontakty.html` → `pages/kontakty.html`
(правило `rewrites` у `vercel.json`). Тому в HTML і JS використовуються **абсолютні шляхи**:
`/assets/...`, `/content/...`, `/images/...`. Посилання між сторінками — просто `kontakty.html`.

## Як влаштована сторінка

Кожна сторінка має однаковий каркас (див. `pages/_template.html`):

1. `<head>` — однаковий набір мета-тегів (title, description, canonical, Open Graph), іконки, шрифти, `styles.css`.
2. `<body data-page="КЛЮЧ">` — ключ потрібен меню (підсвітка пункту) і редактору (яку схему вмісту відкрити).
3. Шапку, меню й футер **не пишемо** — їх додає `site.js`. Гілочку калини в `.page-hero` теж.
4. `<main>` → `section.page-hero` (заголовок сторінки) → далі `section` з `div.wrap` усередині.
5. Внизу: `<script src="/assets/js/site.js">`, потім (якщо треба) `<script src="/assets/js/pages/НАЗВА.js">`.

## Правила коду

- **Жодних `style="…"`** у HTML і JS-шаблонах — тільки класи з `styles.css`.
- Кольори, тіні, радіуси — лише через змінні `:root` (`var(--leaf)`, `var(--kalyna)`, `var(--shadow-soft)`…).
- Новий загальний блок → відповідний розділ `styles.css`; стилі лише однієї сторінки → розділ 14.
- Дрібні відступи — утиліти (`.mt-16`, `.m-0`, `.text-leaf` …), розділ 13.
- Тексти, які має змінювати заклад, не «зашиваються» в HTML: вони беруться з `content/*.json`,
  а HTML містить запасне значення.

## Як додати нову сторінку

1. Скопіювати `pages/_template.html` → `pages/nova-storinka.html` (лише латиниця, цифри, дефіс).
2. Заповнити `<title>`, `description`, `canonical`, `og:*`, `data-page`, вміст.
3. Додати пункт у меню: масиви `NAV` / `MEGA` в `assets/js/site.js`.
4. Додати адресу в `sitemap.xml`.
5. Якщо вміст має редагуватися — створити `content/nova.json`, схему в `assets/js/editor.js`
   (обʼєкт `S` + `PAGE_MAP`) і скрипт `assets/js/pages/nova-storinka.js`, що читає JSON.

## Редактор вмісту

- Кнопка «🔑 Вхід» внизу сторінки → вхід через GitHub (OAuth-додаток «Калинка — редактор»).
- Редагувати можуть лише колаборатори репозиторію. Зміни зберігаються комітом у `content/*.json`,
  файли — у `images/uploads/`. Після збереження викликається `/api/deploy` → Vercel оновлює сайт за 1–2 хв.
- Локальна перевірка без входу: `http://localhost:…/сторінка.html#edittest` (зберігає в консоль).

## Налаштування Vercel (Environment Variables)

| Змінна | Для чого |
|---|---|
| `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET` | вхід у редактор через GitHub OAuth |
| `VERCEL_DEPLOY_HOOK` | передеплой після збереження (обхід блокування комітів не від власника на Hobby) |

Ключ форми «Напишіть нам» (Web3Forms) зберігається в `content/settings.json` → `formKey` і задається через редактор на сторінці «Контакти».

## Локальний запуск

Будь-який статичний сервер, що підтримує правила `vercel.json`, наприклад `npx vercel dev`.
Звичайний `python -m http.server` віддасть головну, але сторінки відкриватимуться за адресою `/pages/….html`.
